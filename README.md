## View it locally

Download `index.html` and open it in any web browser. No installation or build step is needed.

## Update the site

1. Open `index.html` in a text editor and change the text you want.
2. In the GitHub repository, choose **Add file → Upload files** and upload the new `index.html` over the old one.
3. Select **Commit changes**. GitHub Pages republishes the site within a minute or two.
